Common questions

How do I use the planner?
See the Help page.

Why do some numbers show "?"
They depend on live character stats or equipment, such as your crossbow, which the planner can't know.

Does this match the current game version?
Yes, the data is read from the current game files. If you spot a difference, please report it with the build link.

How do I save a build?
Bookmark the page or copy the link. The whole build is in the address.
