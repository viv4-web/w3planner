About

A free, open-source build planner for the current version of the game's skill system: skill trees, mutations, mutagens and ability slots.

Where the data comes from

Skill names, descriptions, values, costs, prerequisites and unlock rules are read from the game's own data files and scripts, and tooltip numbers are calculated with the same formulas the game uses. A few values depend on live character stats (for example crossbow damage); those show as "?" or use the game's base values.

New here? See how to use the planner. If something doesn't match what you see in the game, please let me know.

Open source

The planner's code is open source under the MIT license: github.com/viv4-web/w3planner. The repository includes placeholder artwork I made myself. The game's own artwork is not included, and the license does not cover game names, text or data, which belong to CD PROJEKT S.A.
